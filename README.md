Hello World! 

Welcome to my implementation of the classic game Asteroids, following the Boot.Dev guided lesson.

In order to start, you will need to install pygame on your machine. For example:

python -m pip install pygame

Start the game using the command:

python3 main.py
Click on the "Start Game" button.

Controls:

W: Move forward
A: Rotate Left
S: Move Backwards
D: Rotate Right
Spacebar: Fire

Asteroids will shrink in size when hit. When hit at the smallest size, they will disappear.

Running into an asteroid with the spaceship results in being sent back to the main menu.
